Memo page parts

The smaller pieces of the memo page, each as it sits on the page and with the dialog it opens. Turn on the errors tweak to see the dialogs submitted incomplete.

1. People with access

Right column of every memo page, under the approvers. Replaces the one-line “Can read” summary.

2. Co-authors

Draft and returned memos, right column.

3. Linked memos

The Linked memos tab: links this memo makes, and memos that link to it.

4. Attachments

The Attachments tab while the memo can still be changed. Afterwards the classification, remove and upload controls go.

5. File preview

Opens from the eye button on an attachment or document. Wide dialog on desktop, full screen on phones.

6. Note sheet: corrections and checks

Notes are final. A person can post a correction under their own note; anyone can check an authenticated approval.

7. Final record versions

For an approved or closed memo, when the record failed validation or must be remade.

8. Declared interests

Right column, below People with access. The initiator lists who has an interest while the memo is a draft or returned; everyone who can see the memo reads the list.

9. Search box (⌘K)

In the top bar on desktop. On phones the search icon opens the Search page instead.
