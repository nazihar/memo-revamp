## Acceptance criteria (selection; full list in test-plan.md)
- **T1:** Given any random sequence of commands from the allowed set, the invariants hold after every step: only the assignee of an open task may act; an instance is `APPROVED` only after the last approval of the current round; earlier rounds never count; terminal states accept nothing.
- **T2:** Given two concurrent approvals of the same task with different keys, exactly one succeeds and the other gets `409`; given the same key twice, both get the same response and one action row exists; given the same key from another user, `422`. Given an attempt to update or delete a `workflow_action` row, the database refuses.
- **T3:** Given a user, when they create a draft with a classification below the type's default, then `422`. Given a DOCM renamed `.docx`, the upload is refused (existing files rule). Given another user, `GET /memos/{id}` of a draft → `404`.
- **T4:** Given a route with the initiator, a duplicate, an inactive user or an uncleared user, `PUT /route` answers `422` with a reason per entry. Given an approver whose clearance was lowered after submit, when their step becomes active, the task is created blocked and the initiator and admins are notified.
- **T5:** Given round 1 returned by approver 1, when the initiator uploads v2 and resubmits, then round 2 starts with approver 1, round 1's approvals do not count, and every action row of round 2 carries v2's hash. Given a memo in review, an upload by the initiator through the files API → `403`. Given a type with step-up on and a factor 20 minutes old, approve succeeds; 40 minutes old → `401 step-up-required`.
- **T6:** Given a blocked task, when an admin reassigns it with a reason after step-up, the old task is `REASSIGNED`, a new open task exists for the new approver, both are notified, and the action is audited.
- **T7:** Given 10,000 open tasks in the tenant and 300 for the user, the first inbox page answers within budget with two queries.
- **T10:** The first-slice journey passes in Chromium on every PR and in Firefox nightly, with axe clean on every screen.
