# OWASP ASVS 5.0 checklist

> Target: **Level 2** for all web and API work; **Level 3** for authentication, authorization, cryptography and audit (`AGENTS.md §3.4`). Each row links a requirement to its evidence: a test, a CI gate or a document. The checklist is updated per epic and reviewed at every phase exit (TESTING_STRATEGY §6). Requirement IDs refer to ASVS 5.0.0 (May 2025).
>
> Status values: `met` (evidence linked), `partial`, `planned (phase)`, `n/a (reason)`.
>
> **Phase 4 review (2026-11-28, E08 T11):** every Phase 4 row (E01–E08) was checked against the build. Each cited test, matrix file, rule and runbook exists. No Phase 4 row is `planned` or `partial`. E01 had no rows and now has four, and E08 has its seven. The rows for the privileged search path, the minutes copies, the minutes step-up and action auditing gained the evidence added since. Items that need a person (screen-reader passes, the real-client calendar run, the journeys on dev) are not ASVS evidence; they are carried in `STATUS.md`. The scope for the external pen test is in `pen-test-scope.md`.
